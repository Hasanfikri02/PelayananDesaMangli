# 🏛️ Layanan Desa Digital - Desa Mangli

Sistem Pelayanan Masyarakat Terpadu berbasis Web yang dirancang untuk modernisasi dan efisiensi administrasi desa. Platform ini mempermudah warga dalam mengajukan surat-menyurat secara online, menyampaikan pengaduan, serta membantu perangkat desa dalam melakukan sensus penduduk secara akurat dan cepat.

---

## 🌟 Fitur Utama

- 📜 **Pengajuan Surat Online**: Pembuatan dan permohonan surat administratif desa tanpa perlu antre di kantor desa.
- 📢 **Pengaduan Masyarakat**: Wadah bagi warga untuk menyampaikan aspirasi, keluhan, dan laporan secara transparan.
- 📊 **Sensus & Pendataan Penduduk**: Pengelolaan data kependudukan terpusat untuk mempermudah pembaruan data desa.
- 🔐 **Manajemen Pengguna & Perangkat Desa**: Akses bertingkat untuk warga dan staf administrator/perangkat desa.

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan stack teknologi modern:

- **Framework**: [Laravel](https://laravel.com)
- **Language**: PHP 8.3.16
- **Database**: MySQL
- **Frontend**: Blade Templating, HTML5, JavaScript / Tailwind CSS
